# Drinks Weekend Collections

Adds 10 collections with 38 items to WeekendDrops. Completing each collection gives a permanent **+10% GP bonus** on Weekend rewards: **+100%** for completing all sets in this addon.

## Requirements

- SPT 4.1.6
- WeekendDrops 1.0.7
- [Hood’s More Energy Drinks](https://github.com/Hood26/HoodsEnergyDrinks-CSharp) 1.3.0

## Installation

Close the server and game, then extract the release ZIP into the game folder. It contains:

```text
SPT_Runtime/user/mods/Drinks-WeekendCollections/
BepInEx/plugins/Drinks-WeekendCollections/
```

Every player needs the client plugin for translated collection text. Restart the server and game. English, German, Russian, Brazilian Portuguese and Simplified Chinese are included.

## Collections

- **MONSTER ORIGINALS** — 4 items; 200 GP per donation; 1,000 GP on completion.
- **MONSTER TROPICAL** — 4 items; 200 GP per donation; 1,000 GP on completion.
- **MONSTER DESSERTS** — 3 items; 200 GP per donation; 750 GP on completion.
- **GHOST ORCHARD** — 5 items; 200 GP per donation; 1,250 GP on completion.
- **GHOST SWEETS** — 3 items; 200 GP per donation; 750 GP on completion.
- **ARIZONA OASIS** — 4 items; 200 GP per donation; 1,000 GP on completion.
- **HIGH VOLTAGE** — 5 items; 200 GP per donation; 1,250 GP on completion.
- **C4 FLAVORS** — 3 items; 200 GP per donation; 750 GP on completion.
- **RIP IT PATROL** — 3 items; 200 GP per donation; 750 GP on completion.
- **NIGHT SHIFT** — 4 items; 200 GP per donation; 1,000 GP on completion.

The addon updates only its own completion bonus to 10%; existing donation progress, cash rewards and unrelated collections are preserved. The Weekend configuration file is not overwritten. Bonuses follow Weekend’s normal profile-wipe rules.

## Removal

Remove the two addon folders. Keep the required item mod installed while items remain in profiles. Weekend retains its saved collection data.
